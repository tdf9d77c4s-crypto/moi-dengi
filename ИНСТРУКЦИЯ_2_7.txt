МОИ ДЕНЬГИ — PREMIUM LIVING 2.7

В КОМПЛЕКТЕ: сайт для GitHub Pages, 17 файлов. Все файлы загружайте В КОРЕНЬ репозитория, рядом с index.html. Архив .zip загружать в GitHub не нужно.

ПРЕЖДЕ ЧЕМ ОБНОВЛЯТЬ
1. Откройте текущий сайт, в настройках скачайте резервную копию JSON. Если включён пароль, сохраните его: без пароля зашифрованные данные не восстановить.
2. Убедитесь, что в репозитории ветка main и файлы лежат в корне.
3. Скачайте и распакуйте архив, выделите 17 файлов сайта и загрузите через Add file → Upload files. НЕ загружайте картинки для тестов и README вместо файлов сайта.
4. Нажмите Commit changes. Дождитесь успешной публикации Pages / Actions.
5. Ссылка остаётся https://tdf9d77c4s-crypto.github.io/moi-dengi/
6. Если браузер некоторое время показывает старую версию, подождите обновления service worker и попробуйте перезагрузить страницу. НЕ очищайте данные сайта: можно потерять операции.

ЧТО ИЗМЕНИЛОСЬ В 2.7
* Два атмосферных фона: тёплое горное озеро и вечерний город; фон заполняет страницу целиком.
* Сохранена одна карта с четырьмя счетами.
* У таксы отдельно двигается хвост. Реакции персонажей на нажатие стали выразительнее.
* Обновлены короткие синтезированные звуковые эффекты лая и чашки; звук можно отключить. Это не записанный голос живой собаки.
* Короткая финансовая подсказка, дни записей, более быстрые категории и повтор последнего расхода.
* Мягкие переходы, облегчённые анимации на мобильных устройствах, режим reduce motion.

ВАЖНО О ФОНАХ
Высокодетализированные фотографии подгружаются из Unsplash во время работы в интернете. Для офлайн-режима остаются локальные фоновые изображения. Поэтому внешний вид с интернетом и без интернета может различаться. Это ограничение текущей сборки, которое можно устранить, заменив удалённые фотографии локальными файлами.
