МОИ ДЕНЬГИ 2.6 — PREMIUM WORLDS
================================
Готовое обновление существующего приложения, не демонстрационный макет.

Визуал:
• Капибара: закат, горы, озеро, золотистые огни.
• Такса: фиолетово-синий вечерний город.
• Непрерывный фон при прокрутке, полупрозрачные панели.
• Одна карта с четырьмя счетами в сетке 2×2.
• Переключение героев лапкой в правом верхнем углу.
• Нажатие на капибару — анимация глотка кофе (стилизованное покачивание и пар).
• Нажатие на таксу — анимация лая + короткий синтезированный звук.
• Звук отключается в Настройках. Предпочтения уменьшения движения учитываются.
• Мягкая анимация переходов, небольшие эффекты при нажатии.

Важное ограничение: персонажи — детальные 3D-иллюстрации с CSS-анимацией,
НЕ свободно вращаемые / полностью скелетно анимированные фотореалистичные 3D-модели.
Звуковой эффект лая — синтезированный, а не настоящая аудиозапись собаки.

Сохранены: расходы, доходы, переводы, финансовые цели, недельный бюджет,
категории, история, JSON-резервные копии, защищённый режим.
Используются прежние ключи localStorage, пароли НЕ сбрасываются.
Каждый браузер хранит финансовые записи отдельно; синхронизации между устройствами нет.

------------------
1. Перед обновлением на старом сайте скачайте JSON-копию в Настройках.
2. Распакуйте архив. ZIP целиком на GitHub загружать не нужно.
3. Откройте https://github.com/tdf9d77c4s-crypto/moi-dengi/upload/main
4. Загрузите ВСЕ 14 файлов ниже в корень репозитория. Имена должны быть точными,
   без «(1)» и «(2)». Одинаковые названия заменяют старые файлы.
5. Нажмите Commit changes. Дождитесь успешной публикации GitHub Pages.
6. Откройте https://tdf9d77c4s-crypto.github.io/moi-dengi/
   Если старая версия появляется кратковременно, дождитесь проверки обновления.
