МОИ ДЕНЬГИ 2.9 — PREMIUM ESSENTIAL

Улучшения:
• Персонаж меньше; четыре счета заметнее сразу при открытии.
• Убраны звуки животных из приложения (не просто выключены).
• Фон таксы: новый сдержанный графитово-синий интерьерный стиль.
• Аналитика: круговая диаграмма по категориям в RUP за выбранный месяц. Можно нажать на категорию, чтобы отфильтровать историю.
• Главная осталась простой; одна кнопка быстрого добавления.

Сохранение данных:
Не менялись ключи localStorage, формат JSON и пароль. Однако перед обновлением экспортируй резервную копию JSON. Финансовые данные не загружаются в GitHub.

Установка:
1. Скачай ZIP и распакуй.
2. В GitHub открой репозиторий moi-dengi, выбери Add file → Upload files.
3. Перетащи все файлы из архива именно в корень репозитория рядом с index.html, не сам ZIP. Названия должны быть без (1), (2).
4. Нажми Commit changes.
5. После успешной публикации проверь в приватном браузере новую версию без личных записей, а затем в обычном браузере.

Примечания:
• Аналитика объединяет только карту и наличные в RUP. USD, USDT и RUB не суммируются без курсов.
• На разных устройствах финансовые данные пока не синхронизируются автоматически.
• iPhone/Safari и долгосрочная стабильность должны быть проверены после публикации.
